애니메이션
---------------
서버에서 키 값만 클라에서 넘겨주면 클라에서 애니메이션 재생

데드레코닝
---------------
다음 패킷(움직임)이 오기전에 다음 움직임을 예상해서 보간함(클라에서 구현)

로드 밸런스
---------------
플레이어들이 한게임에 매칭되면 서버 하나 할당
서버 인스턴스를 여러개 띄우고 매칭 서버가 인스턴스 서버를 할당해줌
채팅서버 매칭된 매치마다 할당
인스턴스는 3~5개 목표

공유 데이터
---------------
클라 -> 서버
키인풋, 캐릭터 look dir

서버 -> 클라


로직
---------------
서버 주소 입력 -> 로그인 -> 서버에서 매칭

매칭 성공 
- 클라에서 플레이어 pos, rot, 카메라 pos, rot 보내줌
- 서버는 플레이어 pos, rot을 매칭된 사람들한테 보내줌

움직임
- 클라에서 키 입력, 카메라 look 벡터를 보내줌(move, 카메라 방향으로 총, 스킬을 쓰기 위한 카메라 look)
- 서버에서는 받은 값에 따라 움직임 계산
- 클라로 보내줄 때 플레이어 pos, rot 보내줌
